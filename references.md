# References

*Reference*: Latin *referre*, to carry back. Carry back the quality, never the subject or the layout.

| Reference | What to take |
| --- | --- |
| [Liveline](https://benji.org/liveline) | The bar for charts: a smooth line, a live end dot, a value that rides the line |
| Folio's calendar | The screen Carter spent longest on. The reference for his taste in layout and motion |
| Vermeer, *The Geographer*, 1669 | Window light, one blue robe, a map. Warmth with restraint. Folio's sign-in painting, in the public domain |
| Montessori materials | Plain, self-explanatory, complete. The bar for a foundation screen |
| Aristotle, *Rhetoric* | Ethos, pathos, logos as a working check |
| Nikos Salingaros | Temperature and harmony, the design half of the rubric |
| [unslop](https://github.com/heydamir/unslop), Damir Sokolovsky | Where the first version of this repo began |
