# Code

*Code*: Latin *codex*, a tree trunk, then tablets cut from it, then a book of laws. Code is the law of the thing, written down.

> "code should be brief and elegant. we can express our very PATHOS through the LOGOS of our code."

*Brief*: Latin *brevis*, short. *Elegant*: Latin *elegans*, choosing with care, kin to *eligere*, to pick out. Brief and elegant code is short because someone chose.

- The smallest clear solution wins.
- Delete before adding.
- One concept, one name. See [words.md](words.md).
- No parallel systems. No speculative options. No dead code left behind.
- When a change is larger than the idea behind it, simplify it before it merges.
- Views read theme tokens, never raw values. See [interface.md](interface.md).
